# DSP Simple

无限画布形式的工厂游戏原型。React 18 + React Flow 12 + TypeScript + Zustand + Vite，模拟使用自写轻量 ECS。

## 运行

```powershell
npm install
npm run dev
```

默认访问 http://localhost:5173。构建：`npm run build`；类型检查：`npm run typecheck`；运行已有模拟测试：`npm test`。

## 当前可以做什么

- 初次打开会载入蓝矩阵示例。暖机后可持续产出约 120 个电磁矩阵/分钟，直到仓库装满。
- 建造目录按矿产和设备分类：铁矿、铜矿、采矿机、电弧熔炉、制造台、矩阵研究站、仓库。原型建造不消耗材料。
- 矿脉独立保存剩余储量，不提供物流端口。把采矿机拖到矿脉的任意空闲边缘，出现高亮后松开即可吸附开采；拖离即停止。也可在采矿机详情中选择矿脉，点击「移到矿旁」。
- 一个矿脉的四条边各可吸附一组采矿机，多组设备消耗同一份储量。移动矿脉会带动已吸附的设备，移除矿脉会解除关联并保留采矿机及已采库存。
- 电弧熔炉、制造台和研究站建好后，在「生产目标」中选择对应配方。同一台熔炉可切换铁块、铜块、磁铁；同一台制造台可切换齿轮、磁线圈、电路板。
- 切换目标会取消当前生产、退回已投入的原料，保留全部库存到输出区供回收，并移除不匹配的连线。
- 拖动节点调整布局；拖动空白处平移，滚轮缩放，左下角按钮恢复全图视野。
- 从节点右侧输出端口连接到下游左侧的同物品输入端口；仓库的通用输入接收所有物品。也可依次点击两个端口，或在节点详情中选择物品和接收设施，点击「建立连接」。
- 设备节点内的数字和加减按钮调整设施台数。同一组设备共用生产目标及输入/输出缓冲区。
- 点击节点查看详情。选中节点或连线后按 Delete/Backspace 删除；Shift 框选多个节点。移除设施会同时移除库存与相关连线。
- 顶部控制暂停、继续和 1/2/5 倍速。产量与流量使用 5 秒模拟时间的统计窗口并平滑显示，调整台数后需要等待数个窗口收敛。
- 每 5 秒保存到当前浏览器的 localStorage，也可手动保存。刷新自动读取；隐藏或关闭页面会保存，隐藏期间暂停，不进行离线结算。

存档绑定浏览器和访问地址，`localhost` 与 `127.0.0.1` 的存档互不共享。数据目前仅保存在本地浏览器中。

旧版存档会自动升级为 v2：原采矿节点保留为采矿机，在左侧新增矿脉，保留储量、设备台数、原连线、生产目标、库存和进度。转换前的原始存档备份在 localStorage 的 `dsp-simple-save-v1-backup` 中（浏览器存储可用时）。

## 代码与文档

- `src/game/`：实体、配方、缓冲、生产运输、统计、存档和界面状态桥接。
- `src/ui/`：画布、设施卡片、物流连线、目录与详情面板。
- `tests/`：独立的模拟、设备配置、矿脉吸附和存档迁移检查。
- [设计决策](docs/design-decisions.md)：最新确定的方向和实现边界。
- [玩法总览](docs/design-overview.md)：产线配比、流程、分期计划。
- [科技树资料](docs/dsp-tech-tree.md)：原版科技参考。

当前只覆盖铁铜到蓝矩阵的 P0 产线。模拟仍在主线程；电力、科研、多行星和戴森工程尚未实现。
